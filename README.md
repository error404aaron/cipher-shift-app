# Cipher Shift (published build)

Play: https://error404aaron.github.io/cipher-shift-app/

Static build of CIPHER SHIFT, a fictional sci-fi codebreaking game that runs entirely in the browser (no backend, no accounts; wins are stored in local browser storage only).

This repository holds only the published files. They are copied unchanged from `dist/` of the source repository at release commit `beeeabd85c06b3a99ddd6084775940c19859c652`.
